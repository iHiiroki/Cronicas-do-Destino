# Cronicas-do-Destino
Sistema R.P.G. com Interface Web em Python + Flask

Este relatório documenta o desenvolvimento do sistema Crônicas do Destino, uma aplicação de RPG (Role-Playing Game) construída em Python com o framework Flask. Partindo de uma aplicação de linha de comando simples, o sistema foi reimaginado como uma plataforma web completa, com API REST, interface gráfica interativa, persistência de dados em JSON e motor de aventuras narrativas com nós de decisão. O resultado consolida, na prática, os conceitos de Programação Orientada a Objetos (POO), modularização, tratamento de exceções, design de APIs e engenharia de software aplicada.
